# Bayesian Bike Sharing Project — Module A

Bayesian Statistics group project analysing daily bike rental demand using the UCI Bike Sharing Dataset.

**Module A (Yue)** is responsible for:
- Data preparation and subsampling
- Exploratory data analysis (EDA)
- Frequentist OLS baseline
- Report sections: §1 Introduction, §2.1 Likelihood, §3.2 Frequentist Comparison

## Reproduction

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Step 1: Download dataset (~280KB, auto-skips if already present)
python -m src.download_data

# Step 2: Data preparation (subsample to n=360)
python -m src.data_prep

# Step 3: Exploratory data analysis
python -m src.eda

# Step 4: Frequentist baseline
python -m src.frequentist_baseline

# Step 5: Run tests
pytest tests/
```

## Cross-Module Contract

All team members must adhere to the following:

### Contract 1 — `day_subsampled.csv` column order

```
dteday, cnt, temp, hum, season, yr, mnth, holiday, weekday, workingday, weathersit, atemp, windspeed, casual, registered, instant
```

- `dteday` is the first column, rows sorted chronologically
- D's Sequential Updating slices 4 blocks of 90 via `df.iloc[i*90:(i+1)*90]`

### Contract 2 — `frequentist_results.csv` column names

```
parameter, mle, std_err, ci_lower, ci_upper, p_value
```

Parameter values: `beta_0`, `beta_1_temp`, `beta_2_hum`, `sigma`

B's `posterior_table.csv` should use matching parameter names for easy merge.

### Contract 3 — Random seed

All modules use `random_state=42` / `np.random.seed(42)` for reproducibility.
