# Bayesian Bike Sharing Project — Module B

Bayesian linear regression of daily bike rentals on temperature and humidity, building on the subsampled data produced by Module A.

**Module B (Bo)** is responsible for:
- Weakly informative prior design
- PyMC model construction and NUTS sampling
- Posterior summary table, density plots and forest plot
- Report sections: §2.2 Prior, §3.1 Posterior Inference

## Reproduction

```bash
conda env create -f environment.yml
conda activate bayes

# Step 1: Run MCMC (writes results/trace.nc)
python -m src.model_pymc

# Step 2: Build summary table and plots
python -m src.posterior_summary

# Step 3: Run tests
pytest tests/
```

## Cross-Module Contract

### Input from Module A

`data/day_subsampled.csv` (360 rows, `random_state=42`), with columns:

```
dteday, cnt, temp, hum, season, yr, mnth, holiday, weekday, workingday, weathersit, atemp, windspeed, casual, registered, instant
```

Only `cnt`, `temp`, `hum` are used in the model.

### Output for Modules C and D

`results/trace.nc` — ArviZ `InferenceData` with four chains × 2000 retained draws over `(beta0, beta1, beta2, sigma)`. Consumed by C (sampler diagnostics, prior sensitivity) and D (sequential updating).

`results/posterior_table.csv` — column names matching A's `frequentist_results.csv`:

```
parameter, post_mean, post_sd, ci_lower, ci_upper, ess_bulk, r_hat
```

Parameter names: `beta_0`, `beta_1_temp`, `beta_2_hum`, `sigma`.

### Random seed

All Module B code uses `random_state=42` / `np.random.seed(42)`, matching Module A.

## Model

```
beta_0, beta_1, beta_2 ~ Normal(0, 10000^2)
sigma                  ~ HalfNormal(scale = 3000)
mu_i                    = beta_0 + beta_1 * temp_i + beta_2 * hum_i
cnt_i | mu_i, sigma    ~ Normal(mu_i, sigma^2),  i = 1, ..., 360
```

Justification of hyperparameters is given in `report/section2_2_prior.tex`.
